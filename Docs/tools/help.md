# help

# Description

show help for a tool, or list all available tools

## Usage
```
Usage: pt help [-h] [-l] [--area AREA] [tool]

positional arguments:
  tool         The tool to get help for

options:
  -h, --help   show this help message and exit
  -l, --list   List all available tools
  --area AREA  The area to list tools for
```
