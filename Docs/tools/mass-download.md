# mass-download

# Description

a tool for mass-downloading files from a URL list

## Usage
```
Usage: pt mass-download [-h] [-i INPUT] [-o OUTPUT] [-t THREADS] [URL ...]

a tool for mass-downloading files from a URL list

positional arguments:
  URL                   The URL(s) to download

options:
  -h, --help            show this help message and exit
  -i INPUT, --input INPUT
                        The input file containing the list of files to download
  -o OUTPUT, --output OUTPUT
                        The output folder to download the files to
  -t THREADS, --threads THREADS
                        Number of threads to use for downloading (default: 4)
```
